# Accessibility

Color v2 tokens are chosen for contrast on Command surfaces. Validate your migration against these constraints, especially for destructive actions and form controls.

## Alert button contrast

Destructive actions must remain readable on both white and surface-01 backgrounds.

## Checkbox visibility

Ensure selected, mixed, and alert checkbox paths remain distinguishable at default and hover states. See <DocLink slug="checkbox">Checkbox migration</DocLink> for the full state matrix.

## Dark mode caveat

Dark column values in Figma are labeled **Dark Mode Testing**. Treat them as directional until the platform team validates production dark mode tokens.
