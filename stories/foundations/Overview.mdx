# Color v2 Overview

Color v2 on the Verkada design platform replaces fragmented legacy CSS dialects with **{TOKEN_META.counts['semantic-colors']} semantic tokens** defined once in Figma Collection. Each token has light and dark values.

For rollout strategy, phases, and **platform vs product team ownership**, start with <DocLink slug="strategy">Strategy</DocLink> and <DocLink slug="whoDoesWhat">Who Does What</DocLink>.
