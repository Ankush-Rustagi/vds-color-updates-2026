# Color v2 Overview

Verkada Design System Color v2 replaces fragmented legacy CSS dialects with **567 semantic tokens** defined once in Figma Collection. Each token has light and dark values.

For rollout strategy, phases, and team ownership, start with [Strategy](/docs/intro-to-color-v2-strategy--docs).
