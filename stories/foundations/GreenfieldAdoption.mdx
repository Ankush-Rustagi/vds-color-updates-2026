## Workflow

1. Open <FigmaLink to="collection">Figma Collection</FigmaLink> and bind component variables to semantic tokens
2. In code, use CSS custom properties mapped from Figma names (see <DocLink slug="tokenNaming">Token Naming</DocLink>)
3. Use <DocLink slug="semanticColors">Semantic Colors</DocLink> to look up any token not listed above
