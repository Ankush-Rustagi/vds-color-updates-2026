## Workflow

1. Open [Figma Collection](https://www.figma.com/design/ErBiDvqI7wPQKKXWfhC6yl/VDS---Verkada-Design-System?node-id=73102-139464) and bind component variables to semantic tokens
2. In code, use CSS custom properties mapped from Figma names (see [Token Naming](/docs/reference-token-naming--docs))
3. Use [Semantic Colors](/docs/reference-semantic-colors--docs) to look up any token not listed above
