## Visual deltas teams should expect

- **Alert red tightens** from legacy `#DA5959` to v2 `#CB2939`
- **Surface backgrounds** shift to `--background/surface-01` (canvas) and `--background/surface-02` (cards)
- **Dark mode is in testing** in Figma (column labeled "Dark Mode Testing")
- **Legacy CSS var fragmentation** requires explicit mapping per team dialect (see <DocLink slug="tokenMapping">Token Mapping</DocLink>)

## Engineering impact

1. Replace legacy CSS custom properties with v2 semantic names
2. Validate against Alert Button and Checkbox reference patterns first
3. Use <DocLink slug="semanticColors">Semantic Colors</DocLink> for full token lookup
4. Flag missing tokens to the **platform team** (Meg Kim for Figma, Melina O'Dell for Verity) rather than creating local colors
