## Visual deltas teams should expect

- **Alert red tightens** from legacy `#DA5959` to v2 `#CB2939`
- **Surface backgrounds** shift to `--background/canvas` and `--background/surface-01`
- **Dark mode is in testing** in Figma (column labeled "Dark Mode Testing")
- **Legacy CSS var fragmentation** requires explicit mapping per team dialect (see [Token Mapping](/docs/migrations-color-v2-token-mapping--docs))

## Engineering impact

1. Replace legacy CSS custom properties with v2 semantic names
2. Validate against Alert Button and Checkbox reference patterns first
3. Use [Semantic Colors](/docs/reference-semantic-colors--docs) for full token lookup
4. Flag missing tokens to Design System rather than creating local colors
