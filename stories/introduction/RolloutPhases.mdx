## Phase 2 deliverables (now)

- Semantic Colors, Primitives, Size, and Effects reference tables (searchable)
- Migration guides: Getting Started, Figma Workflow, Token Mapping
- Before/after patterns: Alert Button, Checkbox
- Teams pages with legacy → v2 mapping examples

## Phase 3 expectations for teams

1. Pick one real Command surface (see <DocLink slug="teamsOverview">Teams Overview</DocLink>)
2. Map legacy vars using <DocLink slug="tokenMapping">Token Mapping</DocLink>
3. Rebind Figma components to Collection variables
4. Ship behind feature flag or incremental PR; designer sign-off on reference patterns

## Communication

Eng leads and PMs should set stakeholder expectations early. See <DocLink slug="whatsChanging">What's Changing</DocLink> for alert red, surface background, and dark mode deltas.
